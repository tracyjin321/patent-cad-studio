## 问题与修复

### ISSUE-001：复合机械名称选择错误的主要对象

- 严重度：High
- 复现：`DN50 截止阀 + 双端法兰`生成法兰；`刚性法兰联轴器`生成法兰；滚珠丝杠曾回退为轴承。
- 原因：前端按固定字典顺序选择第一个命中的类别，而不是技术描述开头的主要对象。
- 修复：从描述首句选择最后一个明确命中的机械主体。
- 提交：`35fff06`
- 状态：verified
- 复测：MP-011 → `valve / 阀门技术附图`；MP-026 → `screw / 丝杠技术附图`；MP-031 → `coupling / 联轴器技术附图`。

### ISSUE-002：ISO 标准号被误解析为实例数量

- 严重度：High
- 复现：`ISO 4032 M4 六角螺母`中的 `4032` 被当成数量并截断到 32；`10 图元 ... ISO 4762`也可能产生 32 个螺钉。
- 原因：数量前置正则允许没有“个/枚/件”的裸数字。
- 修复：优先解析部件名后的数量；前置数量强制要求量词；补充 `ISO 4032 M4 螺母`写法。
- 提交：`427f240`
- 状态：verified
- 复测：MP-041/042/043/044/045 分别保持 6/8/7/9/10 个实例。

### ISSUE-003：未知装配静默退化成单轴承

- 严重度：High
- 复现：电机、轴、双轴承、联轴器的装配请求在无具体图元 ID 时返回“轴承技术附图”。
- 原因：生成主流程把空 `component_ids` 解释为单零件参数化生成，没有区分装配意图。
- 修复：带装配意图但没有可执行图元/端口规则时阻止提交，提示开启智能识别或手动选图元；`manual_rules_required` 同样阻断。
- 提交：`e4a7163`
- 状态：verified

### ISSUE-005：图元目录初次展开一次渲染全部卡片

- 严重度：Low
- 现象：150 个图元一次进入 DOM，gstack 可访问性快照超过 900 个交互节点；低高度屏幕上搜索区与生成按钮距离较远。
- 证据：[初始页面截图](../.gstack/qa-reports/screenshots/initial-2026-08-04.png)
- 状态：deferred（Standard 层不修改低优先级体验问题）
- 建议：分类默认折叠或虚拟列表，只渲染当前分类/搜索结果。

## 能力边界结论

- 单零件参数化类别可以稳定生成，并根据描述首句选择正确主体。
- M4 线性紧固栈继续支持 6–10 实例，ISO 标准号不再影响数量。
- 图元与端口规则齐全的装配可以进入 B-Rep、STEP、XCAF 和彩色实例预览链路。
- 齿轮啮合、同步带/链条包络、型材空间分支、多缺失图元等通用装配仍无约束求解器。系统现在会明确阻断，而不是输出错误单零件。
- 本地关闭智能识别时不会请求模型补图元；界面会要求开启智能识别或人工选择。
