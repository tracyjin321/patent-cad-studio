# 专利附图预检与 CAD 工程诊断分层设计

## 目标

将当前混合的 `compliance` 校验拆成两套互不影响的结果：

1. **专利附图自动预检**：依据中国发明、实用新型专利说明书附图的形式要求，对生成的 SVG 做自动预检。
2. **CAD 工程诊断**：检查参数、YAML、B-Rep、尺寸、端口和零件专用结构，不参与专利预检结论。

产品界面必须明确说明自动预检不替代专利代理师或审查员的正式判断。

本设计不覆盖外观设计专利图片或照片要求。

## 法规与官方依据

- 《中华人民共和国专利法实施细则（2023 年修订）》第二十条、第二十一条：
  <https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html>
- 国家知识产权局《专利审查指南》第一部分第一章 4.3、4.6，以及第一部分第二章 7.3：
  <https://www.cnipa.gov.cn/module/download/down.jsp?colID=2790&i_ID=189500>
- 国家知识产权局关于申请文件 A4 规格和留白的公告：
  <https://www.cnipa.gov.cn/art/2013/10/23/art_74_27853.html>

## API 数据模型

生成结果删除旧的混合 `compliance` 字段，新增：

```json
{
  "patent_precheck_status": "pass",
  "patent_checks": [
    {
      "code": "figure_number",
      "name": "附图编号与位置",
      "status": "pass",
      "detail": "检测到图1，位于图形正下方",
      "basis": "专利法实施细则第二十一条"
    }
  ],
  "engineering_checks": [
    {
      "code": "overall_height",
      "name": "整体高度一致性",
      "status": "not_checked",
      "detail": "技术描述未指定总高度"
    }
  ]
}
```

专利检查状态为 `pass | fail | review`：

- `pass`：自动规则有充分证据确认通过。
- `fail`：自动规则发现明确的形式缺陷。
- `review`：法规要求存在，但程序无法可靠完成判断，需要人工确认。

工程检查状态为 `pass | warning | not_checked`：

- `pass`：工程检查通过。
- `warning`：发现几何或规格偏差。
- `not_checked`：用户没有明确给出比较条件，或该检查不适用。

总体专利预检状态计算规则：

- 任一专利项为 `fail` → `fail`。
- 无 `fail` 但存在 `review` → `review`。
- 所有专利项为 `pass` → `pass`。

工程诊断状态绝不参与 `patent_precheck_status`。

参数解析层同时记录尺寸来源，至少区分 `explicit`（技术描述或上传文档明确给出）和 `default`（系统补全）。尺寸一致性检查只接受 `explicit` 参数；Moonshot 返回了数值但原文没有对应尺寸表达时仍视为 `default`，不能据此制造工程警告。

## 专利附图自动预检

### 可自动判断

1. 输出是制图工具生成的 SVG 矢量图，而非照片或工程蓝图。
2. 页面为 A4 纵向比例，图形落在规定留白范围内。
3. 可见线条和文字为黑色，背景为白色且干净。
4. 轮廓线、虚线等线型具有正数且一致的线宽，没有透明或过浅线条，并能满足缩放后的识别阈值。
5. 附图周围没有带描边的无关框线。
6. 图号使用“图1、图2……”格式，位于对应图形正下方。
7. 多幅图的图号连续、无重复，视图之间明显分开。
8. SVG 中没有超出允许集合的多余注释；必要词语应使用中文。
9. 附图页具有连续的阿拉伯数字页码；页码与“图1”等图号是两个独立元素。
10. 将附图缩小到三分之二重新渲染，检查主要轮廓线是否仍然可辨。该结果注明为自动近似判断。

### 需要人工确认

1. 附图是否充分反映要求保护产品的形状、构造或其结合。
2. 在没有完整结构化说明书时，附图标记是否与说明书逐项一致。
3. 局部放大、剖视表达和必要文字是否足以说明特定技术特征。

若上传的专利说明书可提供可靠的附图标记集合，则自动比较说明书与 SVG 标记；否则保持 `review`，不得虚假显示为通过。

原有“无多余中心线/尺寸线”绝对规则删除。中心线、剖面线、标引线并非一律禁止，新的规则只检查线条是否清晰以及文字注释是否必要。

## CAD 工程诊断

保留下列工程检查，但与专利结果分离：

1. 参数是否完整、是否合法。
2. ComponentSpec YAML 是否通过规范校验。
3. B-Rep 是否为有效实体，实体数量是否符合预期。
4. 端口数量、方向和整体结构是否符合生成器预期。
5. 法兰孔、阀门端口、齿轮或丝杠等零件专用结构是否物化。
6. 用户明确输入的尺寸与实际几何包围盒是否一致。

尺寸诊断必须记录参数来源。只有技术描述中明确出现的尺寸才做精确比较；默认值不能触发尺寸偏差警告。例如，用户未输入总高度时：

```text
整体高度一致性：未检查——技术描述未指定总高度
```

组合检查必须拆开。阀体轴向长度和整体高度分别返回结果，不能再共用一个布尔值。

## 页面设计

“参数文档”页按顺序显示：

1. 参数和解析来源。
2. **专利附图自动预检**卡片。
3. **CAD 工程诊断**卡片。

工具栏“合规校验”改名为“专利附图预检”，只反映 `patent_precheck_status`：

- 绿色：自动预检通过。
- 黄色：存在待人工确认项。
- 红色：发现明确未通过项。

工程警告在 CAD 工程诊断卡片中显示，不改变工具栏专利预检状态。

页面固定显示：

> 自动预检仅用于发现常见形式问题，不替代专利代理师或审查员的正式判断。

## 历史记录

不兼容旧 `compliance` 数据。新版首次加载时删除旧 `cad-history`，并使用新的版本化存储键保存包含 `patent_checks` 和 `engineering_checks` 的结果。

历史记录功能继续保留，但只保存新版数据。

## 错误处理

- 某项专利分析异常时，该项返回 `review` 并说明无法自动判断，不把分析器异常误报成法规不合格。
- 某项工程分析异常时返回 `warning`，包含可读原因。
- 缺少用户输入条件时返回 `not_checked`，不使用默认参数制造警告。

## 测试与验收

1. API 测试验证两组检查互不影响。
2. 专利检查覆盖黑白线条、背景、图号、位置、注释、版式和页码。
3. 人工判断项目必须返回 `review`，不得自动标为通过。
4. 未输入总高度的阀门返回 `not_checked`。
5. 明确输入总高度但生成值偏离时返回工程 `warning`，专利状态保持不变。
6. 旧历史被清除，新历史可以保存和恢复两组检查。
7. 浏览器验收至少生成一次电动蝶阀，确认页面分区、颜色和提示文字。

## 非目标

- 不提供授权可能性、创造性或侵权判断。
- 不宣称自动预检等同国家知识产权局正式审查。
- 本阶段不实现完整说明书语义解析、多幅图技术特征映射或外观设计图片审查。
